Daya dukung tiang bor dari N-SPT

Masukkan data tiang dan lapisan tanah. Hasilnya dihitung dengan dua metode sekaligus, lengkap dengan langkah hitungan yang bisa diikuti baris demi baris.

Data tiang

Lapisan tanah

Kedalaman diukur dari muka tanah; kepala tiang dianggap di muka tanah. Data harus mencapai minimal 4d di bawah ujung tiang. Nilai N diisi sebagai N₆₀. Pasir = tanah nonkohesif, lempung = tanah kohesif. Nilai cu hanya dipakai untuk lapisan lempung.

Koefisien Reese & Wright dicocokkan dengan penerapannya di beberapa jurnal teknik sipil nasional. Kode hitungan diuji terhadap perhitungan Python yang ditulis terpisah; skripnya ada di folder tests/.
