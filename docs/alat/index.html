Latihan

Bank soal

Latihan soal geoteknik

Topik
Pondasi dangkal, konsolidasi, tiang bor (9 jenis soal)
Cara kerja
Angka acak, jawaban dicek otomatis (toleransi 2%), pembahasan langkah demi langkah, skor

Cara memakai

  1. Buka kalkulator. Data contoh sudah terisi, jadi hasilnya langsung terlihat.
  2. Ganti data dengan soal atau data proyekmu. Hasil dihitung ulang setiap kali angka berubah.
  3. Baca bagian Penyelesaian untuk melihat rumus dan substitusinya, lalu Catatan untuk asumsi dan batasannya.
  4. Pakai Salin tautan hasil untuk berbagi data yang sama, atau Cetak / simpan PDF untuk lampiran.

Bagaimana hitungannya diuji

Rumus setiap kalkulator dipisahkan dari tampilannya, lalu diuji otomatis di setiap perubahan: dibandingkan dengan perhitungan Python yang ditulis terpisah dan diuji sifatnya. Pondasi dangkal dan konsolidasi juga dicocokkan dengan nilai tabel buku teks (faktor daya dukung untuk φ' = 0°, 20°, 30°, 35° dan Tv untuk U = 50%, 60%, 90%). Contoh soal buku utuh belum ada untuk semua kalkulator; status sumber tiap alat tercantum di README. Hasil pengujian terbaru bisa dilihat di tab Actions.

Alat bantu belajar. Hasil kalkulator tidak menggantikan analisis dan pemeriksaan oleh ahli geoteknik untuk keperluan desain.
